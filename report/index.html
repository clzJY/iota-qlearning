01 / THE QUESTION

What does it mean
to have learned the world?

Imagine a robot moving between rooms to reach its dock. It receives no map of future returns. Instead, it tries an action, observes a reward, and revises an estimate of how useful that action will be. This is the setting for tabular Q-learning.

The assignment asks us to compare an original start/target pair with a new one, A → C. I interpret the robot and dock in its figure as C → F for the original case. The prose does not explicitly identify that original pair, so this is a declared modelling assumption.

Our additional question is more diagnostic: can the robot learn a shortest route while leaving other action values wrong? We answer it using full-table error, coverage counts, repeated seeds, and an exploration ablation.

02 / THE METHOD

One transition.
One revised estimate.

A table entry Q(s, a) estimates the discounted return from taking action a in state s and acting optimally afterwards. Here an action names the adjacent room we enter.

We move the current estimate a fraction α towards a target: the immediate reward plus the discounted best legal next-action value. On entering the goal, there is no future action and the target is just the terminal reward.

The behaviour policy is ε-greedy: with probability ε it chooses uniformly among legal actions; otherwise it selects a maximum-Q action, breaking exact ties uniformly. The update uses a maximum even when exploration selects a different next action. This is the off-policy distinction described by Sutton and Barto [1].

THE UPDATE

Q(s, a) ← Q(s, a)
+ α [y − Q(s, a)]

y = r + γ maxb ∈ A(s′) Q(s′, b)
y = r when s′ is terminal

α controls the size of each revision.
γ makes earlier rewards more valuable.

03 / THE EXPERIMENT

A small world.
An explicit specification.

States and transitions

Each of A–F is a state. Doorways define deterministic, bidirectional edges. Unavailable moves are masked, never penalized as though they were valid actions. The terminal row has no outgoing actions.

Rewards and stopping

Entering the target yields +1; every other move yields 0. Episodes start at the declared fixed room and end at the target. A 100-step cap prevents unbounded sampling; a time-limit truncation still bootstraps because it is not a terminal goal.

With γ = 0.9 and zero intermediate rewards, maximizing discounted return favours the shortest route. We reset Q to zero for every configuration and seed; the modified case is trained from scratch.

04 / REQUIRED RESULTS

The route is short.
The evidence goes further.

VALUE ACCURACY

Full-table error

Ee = max(s,a) valid |Qe(s,a) − Q*(s,a)|, measured after episode e. It includes actions away from the learned route.

OBSERVED STABILITY

Episode change

Δe = max(s,a) valid |Qe(s,a) − Qe−1(s,a)|. Small changes can reflect either accurate values or infrequent updates.

A CHECKABLE REFERENCE

Exact Q*

Q*(s,a) = 0.9d(a,g), where d is the shortest distance from the destination of action a to goal g. Goal entry has d = 0, so Q* = 1.

For this deterministic model, a breadth-first search supplies the exact reference independently of training. A separate value-iteration check agrees for every goal. The learner never uses this oracle for action selection or updates. We call a run empirically accurate at tolerance 10−3 when E remains below that threshold for at least 100 episodes through the end of the run. This criterion is retrospective; we still use the full fixed budget.

A policy can tie without being wrong

For target F, D → B → F and D → E → F are equally short. We break evaluation ties alphabetically when values are exactly equal; small numerical differences may choose a different route. During training, ties are random. The criterion is success and shortest-path length, not a single prescribed sequence.

05 / CONTROLLED COMPARISONS

Change the start.
Then change the goal.

The required comparison changes two variables together. To separate them, we add A → F, B → F, and B → C. Together with A → C, these form a 2 × 2 design: starts A/B and targets F/C. Using B avoids the degenerate C → C episode, which would terminate before taking any action.

With a fixed goal, the optimal Q-table depends on transitions, rewards, and discounting; it does not depend on which start we train from. Start choice still affects which actions receive updates and how quickly the full table becomes accurate. Changing the goal changes terminal boundaries and the values themselves.

A shorter route can leave a slower table.

Holding the goal at F, changing the start from C to A reduces the shortest route from three steps to two. Yet median full-table accuracy moves from 1,119 to 4,769 episodes. The descriptive seed-matched difference is 3,573.5 [2,061.3, 4,774.1] episodes (median [P10, P90]). Starting nearer the goal gives fewer opportunities to sample distant branches in each episode. This interpretation is consistent with the saved visit counts; it is not a universal law about start distance.

The target changes the learning problem.

Holding the start at B, switching target F to C increases the shortest route from one step to two, yet median full-table accuracy improves from 6,286.5 to 1,103.5 episodes. Goal F terminates on entering a well-connected room, while reaching leaf C requires passing through D. Coverage and termination structure matter beyond path length. Final reference tables for the same goal agree regardless of start, while changing the goal changes valid terminal actions and values.

Episode budgets are matched, but exploratory trajectories have different lengths. The table also reports median transition counts so that a comparison in episodes is not mistaken for equal computational or interaction cost. Seed-level results are available in summary.csv. This is a small descriptive study, with no significance claim or claim that 20 seeds characterize every possible random trajectory.

06 / OUR EXTENSION

A quiet table
can still be wrong.

We repeat C → F with ε = 0. Greedy ties are still broken randomly, so this does not mean the run has no initial randomness. Once a route has positive estimates, however, lower-valued alternatives may receive no further attention.

In these saved runs, 20/20 final greedy policies take a shortest route. Nevertheless, final full-table errors range from 0.900 to 1.000, and 0–7 valid action pairs per run were never visited. No run meets the full-table tolerance. Episode changes remain below 0.001 from a median episode of 77 onwards for at least 100 episodes through the run end.

This is why success rate alone is insufficient evidence that the entire Q-table has converged. The robot can execute one good route while being poorly informed about actions it rarely takes.

Stabilization is an observation, not a theorem

We also save the Bellman residual, max |T*Q − Q|, and every state-action visit count. The residual checks consistency with the known model; the counts reveal coverage. In the main required runs, the largest final residual across all 40 runs is 5.55e-16, and every valid pair has at least 2,116 visits. These checks strengthen a finite-run accuracy claim.

The classical convergence result requires repeated sampling and suitable decreasing step sizes [2]. Our constant α = 0.1 and finite budget do not establish those asymptotic conditions. Deterministic transitions make a precise reference possible here; noisy rewards, larger state spaces, alternative graph interpretations, and other hyperparameters could change the picture.

07 / TAKEAWAYS

Three lessons
to carry forward.

01

The goal defines value.

Moving the target changes rewards and the terminal boundary. A new goal generally requires a new value function.

02

The start shapes experience.

Under the same goal, different starts share Q* but expose the learner to different trajectories and coverage bottlenecks.

03

Check more than success.

A good route, a stable table, and an accurate table answer different questions. Compare all three before claiming convergence.

Data dictionary and verification details

results/<case>/seed_XX/ contains initial_q.csv, final_q.csv, visits.csv, snapshots.csv, trace.csv.gz, and metadata.json. Empty Q-table CSV cells mean unavailable actions or the terminal row, never a numeric zero. Trace fields are defined in docs/data-dictionary.md.

The checker validates saved-table legality and bounds, seed metadata and code/config hashes, final error/residual calculations, greedy path lengths, trace lengths, initial values, and local HTML references. With --replay, it reruns seed 0 in each required configuration and compares its complete trace and final table to the submitted evidence.

Reference tables are generated with graph distances and checked against independently implemented value iteration. Diagnostic calculations do not update training values. The report generator reads saved results; it never fabricates or retrains them.
